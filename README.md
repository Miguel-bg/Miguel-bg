<br/>

**Readr** is a web reading app inspired by Kindle.

- Imports books in **EPUB, PDF and DOCX** and renders the text like a sheet of paper, with page-turning.
- Interface built with **Next.js, React, TypeScript and Tailwind CSS**.
- Database migrated from **Supabase to Cloudflare D1**.
- 🔧 *Ongoing:* refining text formatting and reading performance, areas I identified as weak in the first version.
